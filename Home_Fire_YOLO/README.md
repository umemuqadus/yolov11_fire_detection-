# 🔥 Home Fire & Smoke Detection with YOLO

An end-to-end **YOLO object-detection** project that detects **Fire** and **smoke** in
indoor home environments, built on the
[Home Fire Dataset (Kaggle)](https://www.kaggle.com/datasets/pengbo00/home-fire-dataset).

The whole workflow lives in a single, runnable Jupyter notebook:

```
Home_Fire_YOLO_Training.ipynb
```

It covers dataset inspection → validation → visualization → `data.yaml` generation →
training → evaluation → single-image & batch inference → export, all with real (not
fabricated) outputs.

## 🚀 Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

On **Google Colab**, PyTorch is pre-installed — just run the notebook's install cell.

### 2. Place the dataset ZIP (only if not already present)

The notebook looks for `archive.zip` in a few default locations (including your
`Downloads` folder). If it is elsewhere, either move it or edit the `ZIP_PATH`
variable in the **Configure paths** cell of the notebook.

### 3. Open and run the notebook

```bash
jupyter notebook Home_Fire_YOLO_Training.ipynb
```

or open it in **VS Code Jupyter** / **Google Colab** and run the cells top-to-bottom.

> **Training is not launched automatically.** The **Train YOLO** cell has an explicit
> `RUN_TRAINING = True/False` switch that defaults to `False`, so simply opening and
> running the notebook will **not** start a long training job. Set it to `True` when you
> are ready to train.

## 🧭 How the Notebook Is Organized

1. **Introduction** — objective & background
2. **Install dependencies**
3. **Configure paths** — all editable path/config variables in one place
4. **Dataset exploration** — counts, splits, class distribution, dimensions, samples
5. **Dataset validation** — label/image matching, box sanity, corruption, duplicates
6. **Annotation visualization** — ground-truth boxes drawn on real images
7. **Create `data.yaml`** — generated from the verified structure
8. **Train YOLO** — gated behind an explicit flag, with logging & error handling
9. **Training visualization** — real loss/precision/recall/mAP curves from the run
10. **Model evaluation** — val + held-out test metrics, per-class, confusion matrix
11. **Single-image prediction** — adjustable confidence threshold
12. **Batch prediction** — annotated outputs + CSV report
13. **Save & export** — checkpoints, charts, CSVs, optional ONNX
14. **Final summary**

## 🖥️ Environment Notes

- **Windows + VS Code Jupyter:** works out of the box; paths auto-resolve.
- **Google Colab:** the notebook detects Colab and uses `/content/...` paths; you can
  mount Google Drive to persist outputs.
- **GPU (optional):** training auto-uses CUDA when available and otherwise falls back to
  CPU. CPU training is functional but slow — expect it to take considerably longer than
  GPU training.

---

## ⚠️ Known Limitations

- The dataset is **indoor / home-surveillance centric**; expect weaker generalization to
  outdoor wildfires or very different camera setups.
- Smoke is inherently wispy and hard to bound tightly; smoke IoU/mAP is typically lower
  than flame mAP.
- The 135 empty (background) images are kept on purpose — they teach the model to reject
  false positives — but they mean not every image contains a target.
- Metrics reported in the notebook come from **your actual training run**; nothing is
  pre-filled or fabricated. Results will differ with hardware, epochs, and seed.
